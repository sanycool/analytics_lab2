## Содержание решения

Notebook содержит EDA телеметрии и нерегулярных лабораторных замеров,
синхронизацию с задержкой 12 минут, временные лаги, rolling-статистики,
производные и темпы изменения. Сравниваются Ridge, ExtraTrees и
HistGradientBoosting; ARIMA используется как одномерный статистический
ориентир с AIC/BIC. Оценка выполняется на временном hold-out без перемешивания.

Рассчитываются MAE, RMSE, MAPE, WAPE, точность направления, диагностика
остатков и permutation importance. Задержка 12 минут выбрана как середина
диапазона 10–15 минут из условия; для промышленного применения её следует
уточнить по фактическому журналу отбора проб.
